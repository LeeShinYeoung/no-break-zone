# 배포 점검 목록

**deploy는 사람이 한다.** AI는 준비까지 하고 멈춘다 (`CLAUDE.md` §5, `workflow.md` 6장).
release(태그 + 깃허브 릴리스)와 deploy(mod.io·창작마당 업로드)는 다른 일이고, 한 명령에 묶지 않는다.

이 문서는 **확인된 것과 아직 모르는 것을 구분해서** 적는다. 빈칸은 윈도우 세션이 채운다.

## 미확인 — 윈도우에서 채울 것

### 1. 한국어 언어 슬롯 (기획서 §4가 요구)

TextDataBlock의 13개 언어 슬롯 중 **어느 것이 한국어인지 모른다.** 주소가 게임 번들 안
`LanguageDataBlock`을 가리켜서 디컴파일 소스·레퍼런스 모드 어디에도 없다.

**하는 법:** 유니티에서 우리 TextDataBlock을 Scriptable Data Editor로 열면 슬롯마다 언어 이름이
보인다. 한국어가 몇 번째(0부터)인지 확인해 `Editor/genassets.py`의 `LANGUAGE_SLOTS`에 적고
재실행하면 끝난다. 한국어 문안은 이미 스펙에 다 들어 있다.

### 2. 업로드 절차 자체

`workflow.md` 6장이 `확인 필요`로 비워둔 항목들이다. SDK의 에디터 UI를 거치므로 윈도우에서만
확인된다 (`UploadMod.cs` · `SteamWorkshopTab.cs` 존재만 확인됨).

- [ ] 창작마당 업로드 — SDK 내장 기능 사용법
- [ ] mod.io 업로드 절차
- [ ] 필요한 메타데이터 — 태그, 설명문, 썸네일, 의존성
- [ ] 버전을 올릴 때의 주의사항 (기존 구독자에게 어떻게 나가는지)
- [ ] 두 플랫폼에 같은 버전을 올리는 방법

확인한 내용은 `workflow.md` 6장에 채우고, 이 문서는 점검 목록으로만 유지한다.
