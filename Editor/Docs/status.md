**손대지 않은 제안 둘:** 범위 크기·모양 전환은 기획서 6장 "정사각형만"과 11장 "범위 업그레이드 티어
제외"에 걸린다 — 결정이 필요하다. 크리에이티브 모드 목록은 게임에 모드 아이템을 자동으로 모으는 분류가
있는데도(`ModManager.ModObjectsCategory`) 안 보였고, 이유는 아직 모른다.

**사람이 확인할 것** (빌드 전에 게임 본체가 꺼졌는지부터):
1. 파일런 5~6개를 켜 두고, 월드에 막 들어온 상태에서 렌즈를 **처음** 든다 → 끊김이 없어야 한다
2. 렌즈를 든 채 걷는다 → 윤곽이 타일 경계에 붙어 있고 튀지 않아야 한다
3. 네 아이템을 바닥에 버린다 → 바닐라 아이템과 비슷한 크기로 떠야 한다. 파일런·작업대를 손에 들었을
   때도 작게. 모양이 알아볼 만한지 (미리보기: `Editor/Docs/art/preview.png` 아랫줄)
4. `Player.log`에 `no PlacementIcon to copy from` 경고가 없어야 한다

1에서 끊김이 남으면 설치물을 한 번 들었다 놓은 뒤 다시 해본다. 그걸로 사라지면 설치 미리보기 재질을
그래픽카드가 처음 그리는 비용이다 — 코드로는 확인할 수 없었다.

**맥에는 Pillow가 없다.** 이번에는 스크래치패드 가상환경에 깔아 `sprites.py`를 돌렸다. Pillow 버전이
다르면 픽셀이 같아도 PNG 바이트가 달라진다(`remote.png`·`preview.png`·`store_thumbnail.png`에서 확인).
재실행한 뒤에는 **픽셀을 비교해** 판단하고, 안 바뀐 파일은 되돌린다.
